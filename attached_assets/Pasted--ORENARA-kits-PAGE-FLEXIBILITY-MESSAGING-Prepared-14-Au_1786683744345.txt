## Addition — quick-add button at the end of the item list

**The problem:** adding another item currently requires scrolling back up to the "Add an area" row at the top of the page. Once someone's a few items deep configuring things, that's real friction for something that should be quick.

**Recommended behaviour — needs confirmation before building, not settled:** a small "+" affordance appears once, directly after the last item card in the list (below it, before "Installation note"). Clicking it reveals the same four options already at the top — Pool / Path / Stairs / Custom — so someone can add *any* type, not just repeat whatever's already there. This mirrors the existing top row's behaviour, just reachable without scrolling. It should reposition itself to stay after whichever card is currently last, as items are added or removed.

**The alternative, in case this reading is wrong:** the "+" instead quickly duplicates/adds another of the same type as the card it's attached to. This is narrower — useful for "another pool just like this one," but doesn't help if the next thing someone wants is a different type. Confirm which of these two before building either.

**Do not** place a "+" after every card — one, tracking the end of the list, is the right amount. Multiple scattered "+" buttons would be visual clutter for no added benefit.

**Checkpoint:** confirm which behaviour was built (picker vs. duplicate) matches what was actually intended, screenshot the "+" appearing correctly after adding a second and third item, and confirm it repositions correctly if an item is removed.
