Aspect ratio: 4:5 (to match the other kit card images).

**Note on realism:** most 0–10V dimmable strips control brightness, not colour temperature, within a single run — a true warm-to-neutral gradient along one continuous strip usually needs a tunable-white (CCT) product, not a standard dimmable one. If Duskline's actual product is single-CCT with brightness dimming only, consider generating this instead as **two adjacent strips side by side** (one set warm, one set neutral) so the image doesn't overstate a capability the product doesn't have — worth confirming which is true before this goes live.
