# Duskline — AI Image Prompts by Site Section

## Style Anchor (paste this context into every prompt, or prepend it)

> Cinematic dusk/twilight photography. Deep charcoal-navy sky transitioning to warm amber at the horizon. Warm amber-gold LED light (2700K–3000K) as the only strong light source in frame — no daylight, no harsh flash. Australian residential architecture: rendered walls, stone paving, timber decking, native landscaping. Photorealistic, shot on a full-frame camera, shallow depth of field, no visible text, no logos, no people's faces in focus (silhouettes or out-of-focus figures okay for scale). Moody, premium, architectural — not a bright lifestyle catalogue shot.

Use 16:9 for hero/wide sections, 4:5 or 1:1 for kit cards, 1200x630 for the OG/social image.

Camera low to the ground, wide angle, cinematic. No people. No text.

## Notes on Generation

- If using Midjourney: append `--ar 16:9` or `--ar 4:5` per section, and `--style raw` tends to keep these less "AI-glossy" and more photographic
- If using DALL-E/GPT image tools: explicitly repeat "no text, no logos, no watermarks" — these models like to add lettering unprompted
- Keep the color temperature language (warm amber, 2700K-3000K) consistent across every generation — this is what makes the set feel like one cohesive shoot rather than eight unrelated images
- Generate 3–4 variations per section and pick the one where the LED line reads clearly as the focal point — busy compositions bury the product
